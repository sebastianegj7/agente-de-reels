# Biblioteca de música

Pon aquí pistas descargadas a mano, una carpeta por ánimo:

    energico/  tranquilo/  misterioso/  inspirador/  divertido/

`reel.py musica` elige una al azar (fija por título) de la carpeta del ánimo del
reel. Si la carpeta está vacía, genera una base instrumental sencilla.

Fuentes gratuitas sin atribución obligatoria: Pixabay Music (pixabay.com/music)
y Mixkit (mixkit.co/free-stock-music). Revisa la licencia de cada pista. Los MP3/WAV
no se suben a git (ver .gitignore).
